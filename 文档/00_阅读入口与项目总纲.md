# 兽装工作室官网制作文档

版本：1.4 · 编写日期：2026-09-18 · 最近修订：2026-11-04（界面 v5「White Atelier」、无边框按钮、首页精简、周边只展示） · 状态：开发规格，业务确认集中管理。

## 交付边界

本套文档用于开发可商业运营的兽装工作室官网，包含品牌展示、作品与角色、定制委托、商品购买（现货、配件与道具）、洗毛预约、周边展示、网上支付、退款、手机号登录、积分奖励、用户反馈和运营后台。本次交付的是设计与实施文档，没有部署网站，也没有开通商户、发送短信或执行真实交易。

指定技术栈为 Vite + Vue 3 + TypeScript + Tailwind CSS + FastAPI + SQLite。采用模块化单体和增量模型：每个增量均交付前端、接口、数据、测试及部署检查，不把安全、支付、手机号登录留到上线后再补。

本地素材已核验：加载图 `77_双曜弈兽`、积分图 `62_弈环双尾`、Logo `35_逐星绒龙`。原图保持原样，派生资源的规则见素材文档。

## 文档解释规则

- **已明确**：用户指定的能力与素材，开发不可自行删减。
- **设计基线**：为使规格可执行而提出的工程方案；不代表参考站实现方式。
- **Cxx 与待补项**：C01–C33 的确认结论与 N01–N18 待补行只在《功能确认清单-已确认》维护。其他文档仅引用编号，不制造第二份规则。
- **MUST** 表示验收必须满足；**SHOULD** 表示有理由才可偏离；**MAY** 表示可选扩展。
- 冲突处理顺序：用户已确认的最新决定 → 本套文档的单一规则源 → 实际接口契约与迁移记录。代码不能通过改文档把缺陷变成预期行为。
- 价格、积分比例、档期和保修条款均为本项目拟定规则，不能复制参考站的数值或商业承诺。
