# 参考网站调研

调研日期：2026-09-18。目标是覆盖五站从公开入口、站内链接、站点地图及公开客户端路由声明可发现的页面与功能；不是取得网站后台或私有源码后的全量审计。

## 方法与证据等级

从用户指定入口沿同域链接读取页面，保留动态查询参数、详情页与分页，合并说明重复的登录 returnTo。检查 robots/sitemap；当返回单页应用壳时不把 HTTP 200 当有效站点地图。动态站补读页面实际引用的公开前端组件，记录路由声明与界面标签。浏览器读取万物通行动态页面未完成，因此该站多数功能标为组件证据，而非已操作验证。

| 等级 | 含义 | 能证明什么 |
|---|---|---|
| A | 公开页面 HTML/正文或 sitemap 已读取 | 页面及公开字段/文案存在；不证明提交后的后台效果 |
| B | 公开客户端包内的路由/组件/文本 | 声明了入口或预期交互；可能过期或未启用 |
| C | 登录/令牌/当前活动后才可验证 | 仅记录入口/说明；业务成功路径未验证 |
| D | 本项目新增设计 | 来源为用户需求或工程建议，不归到竞品能力 |

未注册账号、发送验证码、上传资料、提交表单、支付、抓取私有 API 或访问他人记录。没有伪造工单号/验证代码来枚举私有结果。

完整 URL 与访问情况见[附录A](附录A_参考站公开路由清单.md)。正文归纳功能族，不用同一个页面的几十个 returnTo 参数夸大独立页面数。站点内容会变化：例如检索缓存中的 ALKAID 展示页为 9 页，本次直接读取为 10 页，附录采用本次读取结果。

## 功能覆盖到本项目

| 能力 | 参考来源 | 本项目结论 |
|---|---|---|
| 品牌/系列/工艺 | 五站不同程度覆盖 | MUST；内容真实、可后台维护 |
| 作品/角色/作者 | WP、ALKAID、Furest、UL | MUST；作品与可售库存分开 |
| 询价/附件/报价反馈 | WP、ALKAID、UL、Halo | MUST；登录保护与报价版本 |

| 合同/制作说明 | WP、Furest、UL | MUST；正式条款独立审核 |
| 手机验证码登录 | 本次未验证任何参考站提供完整实现 | 用户明确要求，D；专门设计 |
| 自有商城/网上支付/退款对账 | 价格/外链/支付方式说明不等于运行证据 | 用户商业要求，D；必须实现 |

| 后台权限/私密素材/运维 | 无后台授权，无法审计 | 本项目商业基础设计，D |

| 多语言/3D/客户故事/转让 | 部分页面或组件有线索 | 记录为 MAY 与 Cxx，不混入必做范围 |

## 2026-11-04 视觉改版参考结论

复查六个指定入口（含已抓取的公开首页与子路由）后的共性：首屏大图/角色、标题短、入口卡片大、价格锚点清楚、流程分步、页脚放品牌图与社交。参考站整体配色克制（暖白/浅灰/黑），本项目保留“清晰价格与卡片入口”；2026-11-04 第二轮视觉反馈后，按 Funiro 的暖米白/陶土棕/柔影与 WP FURSUIT 的大留白/大标题重新定调为 v4「Soft Atelier」，放弃此前的粗描边硬投影版本。

不采用：参考站的第三方建站水印、外链淘宝店铺作为主购买路径、未授权作品图、无法核实的交期数字。设计 token 与文案规则以 11 文档为准。

“所有子路由”在公共调研中只能做到穷尽本次可发现链接及公开路由声明，无法证明不存在未链接、登录后、按活动开放或已下线的页面。本文件与附录保留这些边界；如未来获得参考站正式演示或授权资料，再追加差异记录，不用猜测补齐事实。
