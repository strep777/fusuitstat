# 站点路由与页面功能

本文件定义本项目路由。参考站原始 URL 单独保存在附录，不沿用其技术目录。路径参数为公开随机 ID 或稳定 slug，绝不包含手机号、邮箱、验证码、付款密钥或附件访问凭证。

## 公共区域

| 路由 | 页面与主要功能 | 验收与边界 |
|---|---|---|
| `/` | Logo、品牌介绍、代表作品、接单公告、系列与购买入口 | 首屏可见内容不等加载动画；无内容区域不放假数据 |
| `/about` | 团队、工作方式、制作环境、合作成员 | 人名和照片取得授权；不复制竞品资历 |
| `/contact` | 工作时间、联系渠道、反馈入口 | 外链只允许后台配置的安全协议 |
| `/news` | 公告分类、分页 | 分页状态进 URL |
| `/news/:slug` | 公告正文、发布时间、相关入口 | 下架返回真实 404/410 策略；正文清洗 |
| `/works` | 类型/系列/物种筛选、搜索与分页 | `category/series/species/q/page` 可刷新恢复 |
| `/works/:slug` | 多图灯箱、角色/装师署名、工艺、关联系列 | 无公开授权的委托作品不出现 |
| `/fursuits` | 产品系列概览与适用场景 | 起价标注包含项与不含项 |
| `/fursuits/:slug` | 规格对比、选配、交付内容、FAQ、询价 | 不承诺未经业务核准的交期和性能 |
| `/estimate` | 公开参考估价：系列起价、风格与加项、实时区间、联系方式与隐私同意 | 无需登录；参考区间不是报价；不生成订单；限流 5 次/小时 |
| `/commission/guide` | 可接范围、步骤、量体说明、售后 | 规则有版本；入口清楚 |
| `/commission/schedules` | 开放中/即将开放/结束的委托计划 | 展示时区、开始与截止日期 |
| `/commission/contract` | 合同示例、条款说明、下载 | 标“示例”；真实接受记录只在订单内 |
| `/characters` | 待领养/保留/已领养角色，物种筛选 | 保留不等于成交；售价与授权范围可见 |
| `/characters/:slug` | 设定图、作者、故事、授权、价格、申请/购买 | 卖出禁购买；是否保留展示按 C18 |
| `/shop` | 商品分类、搜索、库存状态 | 分类包括现货/配件/道具/周边；周边只展示；服务按 C28 |
| `/shop/:slug` | 商品图、SKU、价格、运费说明、售后、加入购物车 | 售罄可浏览；禁止前端自行判定可售；周边详情只展示并给出联系入口 |
| `/wash` | 洗毛与护理：套餐对比、流程、预约表单、常见问题 | 需登录提交；期望日期不早于今日+2、不晚于今日+60；服务先申请再报价（C28） |
| `/props` | 道具工坊：道具现货/限量、材质与适配说明、购买入口 | 与 `/shop?category=props` 同源；限量道具仍需审批 |
| `/merch` | 周边展示：徽章、挂件、服饰、毛绒等专题 | 与 `/shop?category=merch` 同源；只展示，不显示价格与加购，不生成订单 |
| `/faq` | 搜索、分类折叠问题 | 折叠项可键盘打开 |
| `/care` | 穿戴、清洁、运输、存放指南 | 使用说明与实际材料一致 |
| `/legal/terms` | 用户服务协议 | 版本号、生效时间、经营主体 |
| `/legal/privacy` | 隐私政策、第三方清单、权利入口 | 说明短信、支付、存储服务和数据用途 |
| `/legal/returns` | 取消/退换/维修规则 | 区分定制与现货，禁止一概“不退不换” |
| `/legal/points` | 积分获取、调整、有效期和申诉 | 与规则版本一致，不用隐藏条款 |
| `/404`、`/maintenance` | 错误/维护提示、恢复入口 | 维护时保留支付查单和客服路径 |

| `/account/orders` | 本人 | 状态筛选、分页、待付款提醒 |

## 运营后台

后台独立入口 `/admin`，采用独立员工登录和 MFA。即使客户已登录，也不能继承员工权限。

| 路由 | 权限码 | 功能 |
|---|---|---|
| `/admin/login` | 无 | 密码 + TOTP/WebAuthn；无公开员工注册 |
| `/admin` | dashboard.read | 订单、报价、任务失败、对账差异；脱敏汇总 |
| `/admin/content/:type` | content.write/publish | 作品、公告、系列、FAQ、团队、法律文本的草稿/预览/发布 |
| `/admin/media` | media.manage | 授权信息、扫描状态、派生图、引用关系 |
| `/admin/products`、`/:id` | catalog.write | 商品/SKU、价格、库存调整、上下架 |
| `/admin/characters`、`/:id` | catalog.write | 角色内容、独占库存、授权规则和售出展示 |
| `/admin/quotes`、`/:id` | quote.review | 分派、补件、版本报价、有效期、拒绝理由 |
| `/admin/schedules` | schedule.manage | 容量、时间窗口、普通申请、候补 |
| `/admin/commissions`、`/:id` | production.write | 节点、私密相册、确认记录、变更单 |
| `/admin/orders`、`/:id` | order.read/fulfill | 明细、发货、关闭原因、售后入口；禁止改已付金额 |
| `/admin/payments` | payment.read | 收款与异常单、渠道查单 |
| `/admin/refunds`、`/:id` | refund.request/approve | 审核、原路退款、失败重查 |
| `/admin/reconciliation` | finance.reconcile | 日账单、差异归因、处置、导出审计 |
| `/admin/feedback`、`/:id` | feedback.review | 去重、回复、奖励等级、申诉 |
| `/admin/points` | points.adjust | 查询流水、调整申请/审批；不允许直接改余额 |
| `/admin/users`、`/:id` | user.read/manage | 脱敏详情、会话撤销、限制状态及原因 |
| `/admin/staff` | staff.manage | 员工角色、MFA、权限变更审计 |
| `/admin/settings` | settings.manage | 经营信息、规则版本、通知模板、功能开关；不展示密钥 |
| `/admin/audit`、`/admin/jobs` | audit.read/ops.read | 审计查询、任务失败、人工重试与死信 |

## 可选扩展路由

仅在相应 Cxx 确认启用后进入导航：`/commission/rush/:roundId`（C11）、`/stories` 与 `/stories/:slug`、`/designers/:slug`（C18）、`/account/transfers/:id`（C29）、`/rewards`（C15）、`/events/:slug`（C20）。多语言使用 `/en/...` 等明确前缀；未翻译的条款不能自动回退后伪装成本地化版本（C24）。`/wash`、`/props`、`/merch`、`/estimate` 属于 FR-025/FR-026 首发范围，同样生成 `/en/wash`、`/en/props`、`/en/merch`、`/en/estimate` 对应路由。

## 所有页面通用验收

每个数据页面 MUST 有 loading、empty、error、forbidden、not-found、success 状态；表单还须有 dirty、saving、saved、validation-error 和 session-expired。401 引导登录并保留不含敏感信息的目标路径；403 不展示对象是否存在的额外信息。404 不能一律返回首页的 200。

提交按钮防连点只改善体验，服务端仍实施幂等。返回、刷新、网络断开和多标签页操作不得重复下单。后台编辑使用 version 字段检测覆盖冲突。私密页面 `noindex` 且响应 `Cache-Control: no-store`，robots 不能替代鉴权。
