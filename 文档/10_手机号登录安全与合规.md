# 手机号登录、安全与合规

该文件给出工程控制与上线核查项，不替代经营主体针对实际业务完成的法律审核。适用范围和第三方服务由 C01–C05、C18/C19/C21/C22 确认。

## 手机验证码登录

使用服务商短信发送验证码，账号在验证成功后按需创建。验证码采用密码学安全随机数生成 6 位数字，初始有效期 5 分钟、重发间隔 60 秒、单挑战最多校验 5 次。同一手机+用途只保留一个有效挑战；重发使旧码失效。验证与消费必须原子化，防并行复用。

验证码存储使用服务端秘密参与的 HMAC，包含 challenge_id、用途和手机号查找值，不保存明文；校验使用常量时间比较。短信日志、链路日志、错误追踪不记录验证码。生产不存在万能码、测试手机号白名单绕过或把 OTP 写入响应的逻辑。

限流初始值：同手机号 1 次/60 秒、5 次/小时、10 次/天；同 IP 20 次/小时后触发额外风险检查；同设备会话限制与总短信预算熔断并用。计数在持久层或共享限流服务原子维护，不能靠一个 worker 的内存。验证码尝试次数按挑战和手机号累计，换 challenge 不绕过总失败限制。

风险升高先要求 CAPTCHA，验证码服务端核验其有效期、用途和一次性。发送成功不代表号码本人验证成功。供应商发送超时不无条件重发：记录未知请求，防重复计费；验证码由本地 challenge 控制，即使短信晚到仍受有效期限制。

参考：[阿里云 SendSms 官方接口](https://help.aliyun.com/zh/sms/developer-reference/api-dysmsapi-2017-05-25-sendsms)。模板、签名、费用、区号支持和参数在供应商确定后复核；其他服务商同样通过 SmsGateway 适配。

## 会话与账号生命周期

- 使用至少 256 位随机不透明 session token，只存其哈希。生产 cookie `__Host-session` 配置 HttpOnly、Secure、Path=/、SameSite=Lax，不设置 Domain。客户默认 7 天绝对期限、24 小时空闲期限，敏感动作要求最近 10 分钟重新验证。
- CSRF token 绑定会话；登录前使用短期匿名 CSRF 会话，防登录 CSRF。写请求同时检查 Origin/受信 Referer，拒绝非预期跨站来源；不能仅靠 SameSite。
- 登录、换绑、权限改变后轮换会话标识。退出/封禁/注销/换绑后按策略撤销其他会话。返回目标只允许本站相对路径，拒绝 `//evil.example` 和编码绕过。
- 换号通常验证旧号与新号；旧号丢失走人工申诉和独立身份/交易证明流程，不能只凭“知道订单号”换绑。换绑后通知原渠道、审计并冻结高风险变更窗口。
- 考虑回收手机号：长期未使用账号在新设备出现异常时进入额外核验；短信证明当前持有号码，不证明拥有历史订单。不得向刚获得号码的人直接泄露旧订单敏感资料。
- 注销区分停止服务、撤销会话、删除非必要资料、隔离依法保留交易记录。对未完订单和售后说明处理路径，不能以任意理由永久拒绝注销。

管理员独立账号、Argon2id 密码哈希和 TOTP/WebAuthn MFA；无公开注册、默认密码或生产共享账号。恢复码哈希保存，MFA 重置须身份核验和审计。敏感财务动作二次验证，并按 C21 实施审批。

参考[OWASP 认证指南](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)。本项目会话时长和速率阈值是设计基线，应根据风险与可用性测试调整。

## 威胁与控制

浏览器是不可信边界；API 是业务权限边界；数据库/对象存储是私密数据边界；短信、支付及 CDN 是第三方边界。

| 威胁 | 攻击例子 | MUST 控制与验收 |
|---|---|---|
| 身份冒充 | 暴力猜 OTP、会话盗用 | 限流、一次性消费、HttpOnly、轮换、MFA；TC-A02/A03 |
| 参数篡改 | 改订单金额、user_id、积分数 | 服务端重算、字段白名单、逐对象鉴权；TC-P04/TC-A04 |
| 抵赖 | 删除报价和退款痕迹 | 版本快照、追加审计、离机留存；TC-C03 |
| 信息泄露 | 用他人附件 ID 下载设定图 | 私有桶、服务端归属检查、短期 URL、no-store；TC-U02 |
| 拒绝服务/费用滥用 | 短信轰炸、上传压缩炸弹 | WAF、持久限流、大小/像素/时间上限、预算熔断；TC-A01/TC-U01 |
| 权限提升 | 内容编辑员调用退款 API | 权限码、默认拒绝、职责分离、审计；TC-A05 |
| 支付伪造 | 仿造回调、修改签名字段 | 原始报文验签、商户金额核对、查单；TC-P03/P04 |
| 供应链 | 泄密包、过期 SDK | 锁文件、来源核查、漏洞与许可证扫描、最小依赖 |

## 应用安全控制

SQL 全参数化；Pydantic 限制长度/枚举/数量/递归体积；排序字段白名单。富文本通过服务端 HTML 白名单清洗，Vue 禁止对用户输入直接 `v-html`。CSP 按支付跳转和图片域名最小开放；禁止万能 `*`，同时配置 frame-ancestors、nosniff、Referrer-Policy 与适当 Permissions-Policy。

同域默认不开 CORS；必要时精确白名单，绝不 `*` + credentials。反向代理仅信任配置的代理 IP，避免伪造 X-Forwarded-For 绕过短信限流。导出的 CSV 防公式注入；后台批量导出需独立权限与审计。

服务器不得抓取用户提供的任意 URL；必须抓取时限制协议/域名，拒绝回环、私网、云元数据、重定向至禁用地址并防 DNS 重绑定。webhook 公网开放但只允许固定路径，限制体积和超时；未知事件只记录最低必要元数据。

## 上传与素材安全

用户附件仅 JPEG/PNG/WebP，最多 3 张、单张 ≤10MiB、最大边长 8192、解码像素总量 ≤4000 万。限制扩展名、MIME、文件魔数、实际大小，尝试安全解码；重新编码派生图、移除 EXIF、扫描后才可用。用户 SVG/HTML/脚本/PDF 首发不接受。原始设计图如需保留，私有隔离且禁止内联执行。

上传路径由服务器生成随机 object key，不信任原始文件名；预签名上传约束 key、大小、类型和过期时间。客户端 complete 后后端 HEAD/读取验证实际文件，再进入扫描状态；不能信任前端 `scan_passed=true`。扫描失败/超时均不发布。

公开作品与私密设定分离；客户未授权的图片绝不放公开 CDN。私密下载 URL 默认 60 秒，签名 URL 不进入日志，用户注销/权限撤销后不再签发。短期 URL 仍是临时持有凭证，不替代下载前鉴权。

## 隐私和保留草案

最小收集原则：浏览不要求登录；询价不收身份证与完整地址；量体仅接单后必要时收集。身体数据及关联照片按高敏感度内部数据保护，并由 C22 评估其法定分类、单独同意与影响评估要求。儿童数据或身份核验另按 C19 设计，不能用一个年龄勾选框宣称已充分履行义务。

洗毛预约只收集登录账号、套餐、期望日期、返还方式（到店/寄回）与备注；寄回地址在订单阶段按收货地址收集，不在预约表重复保存。预约日期与备注按未成交询价同级的 180 天草案清理，审批拒绝后可提前删除。

公开估价只收集称呼、联系方式（加密保存、仅后台可见明文）、角色说明与隐私同意时间，不关联登录账号，不收集身份证件与地址。未成交估价按未成交询价同级的 180 天草案清理；关闭后可提前删除。联系方式不得进入日志、报表或公开渠道。

| 数据 | 拟定保留 | 到期/注销处理 |
|---|---|---|
| 验证码 HMAC | 过期后最多 24 小时清理 | 立即不可再用，定时删除 |
| 未提交询价草稿/孤立上传 | 草稿 30 天；无引用附件 24 小时 | 提前提示，按引用检查清理 |
| 未成交询价与设定 | 结束后 180 天草案 | 需要继续保留则取得适当依据 |
| 量体与制作过程附件 | 售后期结束后 90 天草案 | 删除或不可逆去标识；争议留存例外登记 |
| 安全与访问日志 | 以适用法定义务确定；工程草案至少 180 天 | 最小化日志，限制访问与定期清除 |
| 订单、付款、退款、合同与发票 | 按主体/税务/争议等适用义务制定，不统一承诺 3 年 | 账户注销后隔离，仅为法定义务访问 |
| 反馈与积分 | 业务使用期间及合理争议处理期，C22 定稿 | 匿名化反馈；保留必要账务关联 |
| 备份 | 15 分钟点/日/周分层，最长草案 90 天 | 自动到期销毁；恢复后重新应用删除清单 |

用户可申请访问、复制、更正、删除、撤回展示授权和注销，记录办理状态与理由。短信、支付、存储、监控与统计服务列入第三方处理清单，明确数据类别与用途；客户资料不能发送到开发用语言模型。依据：[个人信息保护法](https://www.nra.gov.cn/xxgk/gkml/ztjg/gfzd/fl/202209/t20220905_338152.shtml)。

## 商业合规落地

经营信息、公示、收据/发票、售后入口、合同证据和公平条款为必须能力。大陆部署核实备案、公安联网备案及所需经营许可；自营售货不简单等同需要某一特定增值电信许可证，也不能一概认为完全不需许可。按实际业务咨询接入商及主管部门。[工信部备案规则](https://www.miit.gov.cn/gyhxxhb/jgsj/cyzcyfgs/bmgz/xxtxl/art/2024/art_84a0cfa0ebd049bbbe751dca9a008e56.html)

定制作说明、退款例外和质量责任分别呈现，未由用户主动确认不适用无理由退货的条件不得暗中扩张。参考[消费者权益保护法实施条例](https://www.mee.gov.cn/zcwj/gwywj/202403/t20240320_1068830.shtml)。

《电子商务法》第三十一条的交易信息不少于三年要求针对平台经营者，不能不辨主体直接套用到本自营站全部数据；同时税务等义务可能要求更久。由 C22 核实并形成数据保留表。[电子商务法](https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_d337c3291e8b40459ca03dea54395856.html)

若采用法定“定金”，C06 必须按《民法典》第五百八十六条核定：超出主合同标的额 20% 的部分不产生定金效力，因此不能把参考站的 50% 首付款直接写作 50% 法定定金。[最高人民法院公布的民法典](https://www.court.gov.cn/zixun/xiangqing/233181.html)。上线前由经营主体审核正式合同与隐私文本，当前文档只定义软件留证和展示能力。
