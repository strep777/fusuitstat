## 加载体验

“双曜弈兽”用于路由初次加载、长表单提交和关键区块加载；局部列表优先骨架屏，避免全页每次闪动。轻微旋转或呼吸动画周期 1.6–2 秒，尊重 `prefers-reduced-motion`，减弱动效时显示静态图及状态文字。

等待少于 150ms 不显示闪烁加载；超过 8 秒给可操作提示，接口超时按业务恢复，不让用户无限等待。支付展示“正在确认支付结果”，不伪造百分比或把动画结束等同成功。页面主内容不为等待全部图片而被遮罩阻挡。

积分小图标尺寸 16/20/24px，可点击权益卡用 32/48px 派生图；每个图标同时显示积分数值与文字单位，读屏只读一次。Logo 在导航使用 32–48px，页脚 40–64px；不要把 1254px 原图在每个积分行重复加载。

## 设计方向（v2，2026-11-04）

风格关键词：**轻快、手作、舞台感**。借鉴参考站的大图、短句、卡片入口与清晰价格锚点，但配色比参考站更活泼：奶油底 + 珊瑚红主色 + 薄荷/葡萄/柠檬点缀。不使用宋体标题、金色渐变、暗棕“复古高级感”这类与兽装工作室气质不符的模板化方案。

设计 token（实现位于 `web/src/assets/main.css`，本表是规则源）：

| 用途 | 值 | 说明 |
|---|---|---|
| 背景 | `#FFF8F0` | 奶油白，比纯白柔和 |
| 表面 / 下沉 | `#FFFFFF` / `#FFEFE4` | 卡片与分区 |
| 正文 / 次要 / 弱 | `#2B2033` / `#6B5D74` / `#97899E` | 李子墨，不用纯黑 |
| 主色 | `#D93A24` | 珊瑚红，白字对比 ≥4.5:1 |
| 主色柔 | `#FFE3DB` | 标签、选中态 |
| 薄荷 | `#0C8F7C` / `#DDF5EF` | 成功、库存、护理 |
| 葡萄 | `#6742E8` / `#EDE7FF` | 链接、专题、夜间点缀 |
| 柠檬 | `#F0A000` / `#FFF1CE` | 提醒、评分；柠檬底必须配墨色字 |
| 夜间 | `#241A2E` | 首屏与页脚，不用纯黑 |

字体：全站圆润无衬线，标题 800 字重、`letter-spacing:-0.01em`；正文 16px、行高 1.65。中文优先 `MiSans / HarmonyOS Sans SC / PingFang SC`，拉丁优先 `SF Pro Rounded / Nunito / Segoe UI`，不加载远程字体。圆角 8/12/20/28/999px，按钮与筛选胶囊使用全圆角；阴影只用于浮层与悬停，不堆叠。

装饰规则：贴纸、点阵、彩条 marquee、手绘箭头可以有，但每屏不超过两种，且不得遮挡正文、价格与按钮；装饰图 `aria-hidden`。动效 160–320ms、轻微弹入，尊重 `prefers-reduced-motion` 与站内“减弱动效”。

正文 16px、行高 1.6；内容区最大宽 1200px，正文阅读区 720px。间距基于 4/8px，按钮触控范围至少 44×44px。产品图完整边缘优先于装饰效果。

文案规则：标题短句化（≤14 字），说明≤2 行；先给结论再给条件；不用“赋能/闭环/极致”等空词；价格必须带“起”或“含”的边界。合规信息（主体、退款、隐私）不能为了简短而删除。

作品网格移动端 1–2 列、桌面 3–4 列；详情页按原图比例，缩略图裁切必须可打开完整图。交易表单单列、错误贴字段、付款摘要始终可见；不能靠颜色表达售罄/已付款/错误。

## 页面布局基线

| 场景 | 信息顺序 |
|---|---|
| 首页 | 导航与接单状态 → 代表作品/品牌短句 → 系列 → 洗毛/道具/周边入口 → 委托步骤 → 商品/角色 → 公告 → 联系与经营信息 |
| 洗毛 `/wash` | 套餐与价格锚点 → 适合谁/不接什么 → 四步流程 → 预约表单 → 常见问题 |
| 道具 `/props` | 道具分类 → 商品网格 → 材质与适配说明 → 限量申请规则 |
| 周边 `/merch` | 周边分类 → 商品网格 → 发货与售后 → 积分说明 |
| 作品详情 | 主图/相册 → 名称及类型 → 工艺与署名 → 关联系列 → 询价入口 |
| 询价 | 委托范围 → 设定图与角色 → 制作需求 → 联系偏好 → 预览与同意 → 提交结果 |
| 报价详情 | 当前版本/有效期 → 明细与总额 → 首期/尾款 → 包含及例外 → 条款 → 接受或重新评估 |
| 商品购买 | 图片 → SKU/库存 → 价格/运费 → 售后 → 购买按钮 |
| 订单 | 当前需要的动作 → 金额及支付记录 → 商品/合同 → 制作或物流 → 售后 |
| 积分 | 可用与待入账 → 获得方式 → 流水 → 规则/申诉 |
| 后台详情 | 状态/负责人 → 业务信息 → 允许动作 → 时间线和审计 |

所有素材尚不齐全的区块建立 CMS 草稿，不用他人作品假装案例。内容负责人须准备：工作室名称简介、系列参数、原创作品授权、商品与 SKU、联系信息、真实制作周期、委托/售后条款和隐私文本。

## 无障碍与错误恢复

图片替代文本描述角色与角度，纯装饰为空。表单 label 可关联；验证码输入支持一次性验证码填充；错误汇总带跳转焦点。灯箱/对话框有焦点圈定、Esc 关闭和关闭后返回原控件。表单刷新丢失前提示，敏感草稿只存服务端。

网络失败应说明可重试的动作，用户无需重新填写全部信息。禁用按钮旁说明原因，如“报价已过期”；支付失败区别“未付款”与“结果尚未确认”。后台危险动作显示具体对象、金额、后果，不能只有泛用“确定”。

## 图片性能与 SEO

作品生成 320/640/960/1440 宽派生图，使用 srcset/sizes 与固定 width/height，保留 WebP/JPEG 兼容方案，AVIF 仅实测收益后启用。首屏主图优先，折叠下懒加载；不自动播放大视频，3D/视频需按需加载和静态替代。

公开内容使用独立 title、description、canonical、OG 图、面包屑；生成只含已发布公共 URL 的 sitemap。过滤参数只为必要索引页面保留，避免无限组合。作品署名和商业信息真实；Product 结构化数据的价格、库存、评价与页面一致，不虚构五星评价。

内容发布触发受控预渲染任务、校验并原子替换静态页面。静态商品价格只用于展示，结算必查实时服务端。用户中心、付款、后台、未公开报价不进入 sitemap，禁止预渲染个人资料。
